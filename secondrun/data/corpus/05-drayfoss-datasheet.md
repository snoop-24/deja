# Drayfoss Mobility — Drayfoss Corridor Product Datasheet

**Vendor:** Drayfoss Mobility AB (Gothenburg, SE)
**Product:** Drayfoss Corridor
**Datasheet revision:** 2026-06-02

## Overview

Drayfoss Corridor is a premium telematics platform aimed at long-haul operators.
Drayfoss competes on data quality and integration depth rather than price.

## Hardware — DC gateway

| Attribute | Value |
|---|---|
| Model | DC-77 |
| Cellular | Dual eSIM, 5G NR |
| Positioning | GNSS multi-constellation with dead-reckoning |
| CAN interfaces | 2× FMS, 2× J1939 |
| Operating temperature | −40 °C to +80 °C |
| Firmware branch | 7.x |

## Firmware

The DC-77 gateway ships on firmware 7.3.0.

## Platform capabilities

- Driver-hours capture with tachograph integration
- Cross-border segment tagging
- Fuel, AdBlue and payload telemetry
- Configurable telemetry cadence from 1 s to 60 s
- REST, streaming and bulk-export APIs
- Predictive maintenance module

## Hosting

Hosted in Stockholm with a secondary site in Frankfurt. Both inside the
European Union.

## Support

24/7 platform support. Named account engineer at all volumes.
99.95% monthly availability target.
