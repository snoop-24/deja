# ECTR Certification Register — Extract

**Source:** ECTR public certification register, commercial telematics section
**Extract taken:** 2026-06-18
**Scope of extract:** the four platforms in the Meridian tender

The register records, for each certified platform, the annex it is certified
against and the minimum firmware build the certification covers. Deploying a
build below the minimum voids certification for that unit (see ECTR-2026
Annex C §4.2).
